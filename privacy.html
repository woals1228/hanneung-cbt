개인정보 처리방침

한국사 CBT(이하 '앱')는 회원가입 없이 쓰는 학습 앱이에요. 이름, 이메일, 전화번호 같은 개인 식별 정보는 받지 않아요.

1. 이용 나이

이 앱은 만 14세 이상만 이용할 수 있어요.

2. 모으는 정보와 이유

  • 무작위 이용자 번호: 기기에서 만든 임의의 번호예요. 누구인지 알 수 없어요.
  • 이용 기록: 날짜(한국 날짜)와 한 일의 종류(방문, 문제 채점, 해설 열기 등)만 하루 한 줄씩 남아요. 어떤 답을 골랐는지는 보내지 않아요.
  • 기기 종류: 안드로이드 / 아이폰 / 앱 안 브라우저 / 기타 중 하나
  • 알림 구독 정보(알림을 켠 경우만): 브라우저가 만든 알림 주소와 고른 알림 시간

이 정보는 앱을 계속 만들지 정하기 위해 '다시 찾아오는 사람이 얼마나 되는지' 세는 데에만 써요. 문제 풀이 기록, 오답노트, 점수는 내 기기 안에만 저장되고 밖으로 보내지 않아요.

3. 보관 기간

  • 이용 기록: 2026년 12월 31일에 모두 지워요.
  • 알림 구독 정보: 알림을 끄거나 구독이 만료되면 바로 지워요.

4. 맡기는 곳

  • Supabase: 이용 기록과 알림 구독 정보 저장
  • GitHub: 앱 호스팅과 알림 발송

다른 곳에 팔거나 넘기지 않아요.

5. 내 기록 지우기

앱의 설정 → 기록 초기화를 누르거나 브라우저의 사이트 데이터를 지우면 기기 안의 기록과 이용자 번호가 지워져요.
