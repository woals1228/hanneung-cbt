# 한국사 CBT (1단계)

기념일 문제, 오답노트, 실전 CBT 모의고사로 한국사능력검정시험(심화)을 준비하는 웹앱(PWA)이에요.
설치 없이 브라우저에서 열 수 있고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 1단계에 들어간 기능

| 화면 | 내용 |
|---|---|
| 홈 | 오늘의 문제(바로 풀기), 시험 D-day, 🔥 연속 학습, 오답 복습 개수, 다가오는 기념일 |
| 기념일 카드 | 기념일 당일에는 "오늘은 ○○", 3일 전부터는 "D-3 ○○" 카드와 관련 문제 |
| 전야제 카드 | 시험 전날·당일에 빈출·예상 주제 문제 세트 |
| 빠른 문제 / 시대별 | 5지선다로 풀고 바로 정답·해설 확인, 틀리면 오답노트에 자동 저장 |
| 오답노트 | 틀린 문제를 1일 → 3일 → 7일 뒤에 다시 보여 줌, 세 번 연달아 맞히면 완료 |
| 실전 모의고사 | 시간 제한 CBT, 답안표, 문항별 1~3점 배점, 100점 환산, 예상 급수(1·2·3급) |
| 내 분석 | 시대별 정답률과 약점 시대, 최근 7일 학습량, 모의고사 기록 |
| 설정 | 앱 설치 안내, 테스트용 날짜 바꾸기, 기록 초기화 |

학습 기록은 그 기기의 브라우저에만 저장돼요. (로그인·기기 간 동기화는 3단계 예정)

## 실행하기 (내 컴퓨터에서)

```bash
npm start
```

그다음 브라우저에서 http://localhost:5173 을 열면 돼요. Node.js만 있으면 되고 따로 설치할 패키지는 없어요.

## 문제 추가·수정하기

문제는 [data/questions.json](data/questions.json)에 있어요. 문제 하나는 이렇게 생겼어요.

```json
{
  "id": "an-1003",
  "era": "고대",
  "topic": "고조선",
  "anniversary": "10-03",
  "points": 1,
  "question": "개천절(10월 3일)은 누가 나라를 세운 것을 기념하는 날일까요?",
  "choices": ["주몽", "단군왕검", "온조", "박혁거세", "김수로"],
  "answer": 2,
  "explanation": "개천절은 단군왕검이 ... 기념하는 국경일이에요.",
  "source": "직접 작성(샘플)"
}
```

- `id`: 겹치지 않는 이름
- `era`: `선사`, `고대`, `고려`, `조선`, `근대`, `일제 강점기`, `현대` 중 하나
- `topic`: 주제 (전야제 주제와 이름이 같아야 전야제 세트에 들어가요)
- `anniversary`: 기념일 문제일 때만 `"MM-DD"` (없으면 빼요)
- `points`: 배점 1~3
- `choices`: 보기 5개
- `answer`: 정답 번호 **1~5** (① = 1)
- `source`: 출처 (기출문제를 넣을 때는 회차를 적고, 이용 조건을 먼저 확인하세요)

고친 다음에는 꼭 검사를 돌려 주세요. 빠진 값이나 잘못된 번호를 알려 줘요.

```bash
npm run check
```

## 기념일·시험 일정·전야제 주제 바꾸기

- 기념일: [data/anniversaries.json](data/anniversaries.json) — `related`에 다른 날짜를 넣으면 그날 문제를 빌려 써요. (예: 현충일 → 6·25 문제)
- 시험 일정: [data/exams.json](data/exams.json) — `date`, `apply`(접수 기간)를 공식 공고에 맞게 바꿔요.
- 전야제 주제: 같은 파일의 `eveTopics`에 주제 이름을 넣어요. 지금 들어 있는 주제는 샘플이에요.
  유튜브 전야제 강의 등을 참고할 때는 **주제만** 가져오고, 영상 속 문제나 자료를 그대로 옮기지 마세요.

## 기념일·전야제 화면 미리 보기

- 설정 → **테스트용 날짜**에서 날짜를 고르면 그날처럼 동작해요. (앱을 닫으면 원래 날짜로 돌아가요)
- 또는 주소 뒤에 `?today=2026-11-27` 을 붙여서 열어도 돼요.

## 휴대폰에 배포하기 (무료)

홈 화면 설치와 오프라인 기능은 **https 주소**에서만 동작해요. GitHub Pages를 쓰면 무료로 올릴 수 있어요.

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. 저장소 **Settings → Pages**에서 브랜치를 `main`, 폴더를 `/ (root)`로 고르고 저장해요.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소가 생겨요. 휴대폰에서 열고 홈 화면에 추가하면 끝!

Cloudflare Pages, Netlify 같은 곳도 같은 방식으로 올릴 수 있어요.
새 파일을 추가했다면 [sw.js](sw.js)의 `SHELL` 목록에도 넣고 `CACHE` 이름의 숫자를 올려 주세요.

## 폴더 구성

```
index.html             앱 화면 틀
manifest.webmanifest   홈 화면 설치 정보 (이름, 아이콘)
sw.js                  오프라인용 서비스 워커
css/style.css          디자인 (밝은/어두운 화면 모두)
js/app.js              시작점, 화면 전환
js/data.js             문제·기념일·시험 데이터 읽기
js/store.js            학습 기록 저장 (오답노트 복습 일정 포함)
js/dates.js            날짜 계산, 테스트용 날짜
js/ui.js               문제 카드, 확인 창 등 공통 조각
js/views/*.js          화면별 코드 (홈, 문제, 오답노트, 모의고사, 분석, 설정)
data/*.json            문제·기념일·시험 일정
tools/serve.js         개발용 로컬 서버 (npm start)
tools/check-data.js    문제 데이터 검사 (npm run check)
```
